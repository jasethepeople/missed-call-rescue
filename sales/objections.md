# Missed-Call Service: Objection Guide

Each response is two sentences, honest, local, and low-pressure.

## "I'm too busy."
That's exactly when it helps: callers get a quick text while you're with a customer or on a job. I'm local, so I can show you the setup in a few minutes—or leave you to it if today is packed.

## "I already have voicemail."
Voicemail is useful, but some callers hang up instead of leaving a message. I'm local, so I can show you how the text option fits alongside voicemail, and you can approve the wording before deciding.

## "It's too expensive."
Fair: setup is $149, plus $20/month for texting paid by you, so it has to make sense for your call volume. I'm local and can do the break-even math with your real job value; if it doesn't add up, skip it.

## "I don't want to confuse my customers."
I'm local, so we can review the short message and your business name together before launch. If it doesn't sound like something you'd send, we won't turn it on.

## "I need to think about it."
Of course; it's worth checking whether missed calls are a real problem for your business. I'm local, and here's [the demo](https://nonobody.zo.space/demo) if you'd like to look before deciding.
